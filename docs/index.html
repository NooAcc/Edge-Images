使用文档

通过 /api/image 接口传入远程图片 URL 和处理参数，服务会返回经过缩放、 裁剪或填充后的 WebP 图片，并自动限制输出尺寸不超过 1024 x 1024。

快速调用

/api/image?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&width=800&height=600&fit=cover

HTML 示例

<img
  src="/api/image?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&width=800&height=600&fit=cover"
  alt=""
>

参数说明

参数 说明 默认值
url 必填，完整 HTTP 或 HTTPS 图片地址，需要 URL 编码。 无
width 目标宽度，最大 1024。仅传宽度时，高度按比例推断。 按源图推断
height 目标高度，最大 1024。仅传高度时，宽度按比例推断。 按源图推断
fit inside、cover、contain、fill、outside。 inside
quality WebP 输出质量，范围 1 到 100。 85
background 填充背景色，格式为 RRGGBB，适用于 contain。 FFFFFF
rotate 旋转角度，支持 90、180、270。 不旋转
flip 翻转方向，支持 h、v、hv。 不翻转

常用场景

  • 卡片缩略图：width=640&height=360&fit=cover
  • 头像：width=256&height=256&fit=inside
  • 商品图：width=800&height=800&fit=contain&background=FFFFFF
  • 低带宽预览：width=480&quality=50

源图域名白名单

生产环境建议配置 IMAGE_URL_ALLOWLIST，限制接口只能下载可信域名下的图片。 

IMAGE_URL_ALLOWLIST=example.com,trusted-cdn.com

每个条目只需要写域名。配置 example.com 后，example.com 和 *.example.com 都会通过白名单。

  • example.com：允许根域名和所有子域名。
  • trusted-cdn.com：允许该域名及其所有子域名。
  • *：允许所有域名，仅建议本地开发使用。

未配置该变量时，白名单不启用，以保持原有开放图片代理行为。

响应与错误

成功处理后返回 Content-Type: image/webp。

参数错误返回 400，源图下载失败返回 502。源图已下载但处理失败时，接口会透传原图，并添加 X-Processing-Error 响应头。

缓存策略：浏览器 1 天，Vercel CDN 7 天。
