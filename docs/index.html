使用文档

通过 /api/image 接口处理远程图片和视频，支持缩放、裁剪、格式转换和元信息查询。

📷图片处理

快速调用

/api/image?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&width=800&height=600&fit=cover

HTML 示例

<img
  src="/api/image?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&width=800&height=600&fit=cover"
  alt="示例图片"
>

获取图片元信息

图片元信息查询只读取源图前 5KB，并直接解析源图元数据。sourceSize 表示源文件总字节数；源站没有返回可靠大小响应头时为 null。

/api/image?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&format=json

JSON 返回示例

{ "width": 800, "height": 600, "format": "jpeg", "channels": 3, "sourceUrl": "https://example.com/photo.jpg", "sourceContentType": "image/jpeg", "sourceSize": 2483921 }

常用场景

  • 卡片缩略图：width=640&height=360&fit=cover
  • 头像：width=256&height=256&fit=inside
  • 商品图：width=800&height=800&fit=contain&background=FFFFFF
  • 低带宽预览：width=480&quality=50

🎬视频处理

自动识别 .mp4 和 .webm 文件，提取首帧作为封面图。采用 Range 请求优化，仅下载前 512KB 数据。

提取视频封面

/api/image?url=https%3A%2F%2Fexample.com%2Fclip.mp4&width=800&height=600&fit=cover

HTML 示例

<img
  src="/api/image?url=https%3A%2F%2Fexample.com%2Fclip.mp4&width=800&height=600&fit=cover"
  alt="视频封面"
>

获取视频元信息

/api/image?url=https%3A%2F%2Fexample.com%2Fclip.mp4&format=json

JSON 返回示例

{ "width": 1920, "height": 1080, "codec": "h264", "duration": 10.5, "format": "mov,mp4,m4a,3gp,3g2,mj2", "sourceUrl": "https://example.com/clip.mp4", "sourceSize": 8349123 }

视频元信息字段说明

字段 说明
width 视频宽度（像素）
height 视频高度（像素）
codec 视频编码格式（如 h264、vp9）
duration 视频时长（秒）
format 容器格式
sourceSize 源文件总字节数；源站没有提供可靠大小响应头时为 null

⚙️API 参考

接口地址

GET /api/image

必需参数

参数 说明 默认值
url 必填，完整 HTTP 或 HTTPS 媒体地址，需要 URL 编码。 无

可选参数

参数 说明 默认值
width 目标宽度，最大 1024。仅传宽度时，高度按比例推断。 按源媒体推断
height 目标高度，最大 1024。仅传高度时，宽度按比例推断。 按源媒体推断
fit inside、cover、contain、fill、outside。 inside
quality 输出质量，范围 1 到 100。 85
format 输出格式：webp、jpeg、png、avif、json。 webp
background 填充背景色，格式为 RRGGBB，适用于 contain。 FFFFFF
rotate 旋转角度，支持 90、180、270。 不旋转
flip 翻转方向，支持 h、v、hv。 不翻转

源媒体域名白名单

生产环境建议配置 IMAGE_URL_ALLOWLIST，限制接口只能下载可信域名下的媒体。 

IMAGE_URL_ALLOWLIST=example.com,trusted-cdn.com

配置规则：

  • example.com：允许根域名和所有子域名。
  • *：允许所有域名，仅建议本地开发使用。

响应状态码

状态码 说明
200 成功处理或降级返回原媒体。
400 请求参数缺失或非法，或源域名不在白名单。
405 请求方法不是 GET。
502 源媒体无法下载、超时或处理失败。
缓存策略：浏览器 1 天，Vercel CDN 7 天。支持 sharp 图片处理和 ffmpeg 视频处理。
