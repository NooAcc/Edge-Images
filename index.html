Vercel Node.js 图片处理服务

把远程图片转换为统一、轻量的 WebP 输出

这个程序接收第三方图片 URL，根据查询参数完成缩放、裁剪、填充、旋转和翻转， 并把最终图片限制在 1024 x 1024 以内，适合作为前端动态图片 CDN 使用。

WebP quality 85 max 1024 x 1024

核心功能

远程图片代理

通过 url 参数下载源图，下载超时和错误会返回明确的 HTTP 状态。

尺寸与裁剪

支持 scale-down、cover、contain、pad 和 crop。

WebP 优化

默认输出 WebP，质量为 85，可通过 quality 参数调整压缩程度。

边缘缓存

返回适合 Vercel CDN 的缓存头，相同查询参数可复用缓存结果。

安全控制

可用 IMAGE_URL_ALLOWLIST 限制源图域名，宽高和源图大小也有上限。

失败降级

源图已下载但处理失败时，会透传原图并附带 X-Processing-Error。

调用方式

/api/image?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&width=800&height=600&fit=cover

在页面中直接把这个地址放进 <img> 的 src 即可。 源图片地址需要先用 encodeURIComponent 编码。

常用参数

参数 说明 默认值
url 必填，远程图片的完整 HTTP 或 HTTPS 地址。 无
width / height 目标宽高，最大值会被限制为 1024。 按源图比例推断
fit 缩放模式，支持 scale-down、cover、contain、pad、crop。 scale-down
quality WebP 输出质量，范围 1 到 100。 85
background contain 和 pad 的填充背景色，格式为 RRGGBB。 FFFFFF
rotate / flip 旋转支持 90、180、270；翻转支持 h、v、hv。 不旋转、不翻转
