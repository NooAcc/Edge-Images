图片处理

通过 /api/media 接口处理远程图片，支持缩放、裁剪、格式转换和元信息查询。

快速调用

/api/media/https%3A%2F%2Fexample.com%2Fphoto.jpg?width=800&height=600&crop=centre

HTML 示例

<img
  src="/api/media/https%3A%2F%2Fexample.com%2Fphoto.jpg?width=800&height=600&crop=centre"
  alt="示例图片"
>

获取图片元信息

图片元信息查询只读取源图前 5KB，并直接解析源图元数据。sourceSize 表示源文件总字节数；源站没有返回可靠大小响应头时为 null。

/api/media/https%3A%2F%2Fexample.com%2Fphoto.jpg?format=json

JSON 返回示例

{ "width": 800, "height": 600, "format": "jpeg", "channels": 3, "sourceUrl": "https://example.com/photo.jpg", "sourceContentType": "image/jpeg", "sourceSize": 2483921 }

常用场景

  • 卡片缩略图：width=640&height=360&crop=centre
  • 头像：width=256&height=256&size=down
  • 商品图：width=800&height=800&background=FFFFFF
  • 低带宽预览：width=480&quality=50

查询参数

参数 说明 默认值
width 目标宽度（px），上限 2048 按源媒体推断
height 目标高度（px），上限 2048 按源媒体推断
crop 裁剪策略：none、centre、attention、entropy none
size 缩放行为：both、down、up、force both
quality 输出质量，1–100 90
format webp、jpeg、png、avif、json webp
background 填充背景色，RRGGBB 格式，适用于 contain FFFFFF
rotate 旋转角度：90、180、270 不旋转
flip 翻转方向：h、v、hv 不翻转
