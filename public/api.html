API 参考

完整的 API 接口文档，包含请求参数、响应头和状态码说明。

接口地址

/api/media/https%3A%2F%2Fexample.com%2Fphoto.jpg?width=800&height=600&fit=cover 
GET /api/media/<encoded-source-url>

必需路径参数

参数 说明 默认值
encoded-source-url 完整 HTTP 或 HTTPS 媒体地址，需要使用 encodeURIComponent 编码。 无

可选查询参数

参数 说明 默认值
width 目标宽度（px），上限 2048。仅传宽度时，高度按比例推断。 按源媒体推断
height 目标高度（px），上限 2048。仅传高度时，宽度按比例推断。 按源媒体推断
fit inside、cover、contain、fill、outside inside
quality 输出质量，范围 1 到 100。 90
format 输出格式：webp、jpeg、png、avif、json webp
background 填充背景色，格式为 RRGGBB，适用于 contain。 FFFFFF
rotate 旋转角度，支持 90、180、270。 不旋转
flip 翻转方向，支持 h、v、hv。 不翻转

请求头

请求头 说明 示例
Accept 可选。指定客户端接受的响应内容类型。 image/webp, image/*
If-None-Match 可选。配合 ETag 实现条件请求，减少重复传输。 "abc123"

请求示例

GET /api/media/https%3A%2F%2Fexample.com%2Fphoto.jpg?width=800&height=600&fit=cover HTTP/1.1 Host: your-domain.com Accept: image/webp, image/*

响应头

响应头 说明 示例
Content-Type 响应内容类型。 image/webp
Cache-Control CDN 和浏览器缓存策略。 public, max-age=31536000, immutable
X-Processor 处理引擎标识。 edge-image
X-Image-Width 输出图片宽度（像素）。 800
X-Image-Height 输出图片高度（像素）。 600
X-Image-Format 输出图片格式。 webp
X-Image-Size 输出图片大小（字节）。 45678
X-Processing-Error 降级响应时，包含错误信息。 Image processing failed

成功响应示例

HTTP/1.1 200 OK Content-Type: image/webp Cache-Control: public, max-age=31536000, immutable X-Processor: edge-image X-Image-Width: 800 X-Image-Height: 600 X-Image-Format: webp X-Image-Size: 45678 [二进制图片数据]

降级响应示例（处理失败，返回原图）

HTTP/1.1 200 OK Content-Type: image/jpeg Cache-Control: public, max-age=31536000, immutable X-Processor: edge-image X-Processing-Error: Image processing failed [原始图片数据]

JSON 响应示例（format=json）

HTTP/1.1 200 OK Content-Type: application/json; charset=utf-8 Cache-Control: public, max-age=31536000, immutable X-Processor: edge-image { "width": 800, "height": 600, "format": "jpeg", "channels": 3, "sourceUrl": "https://example.com/photo.jpg", "sourceContentType": "image/jpeg", "sourceSize": 2483921 }

错误响应示例

HTTP/1.1 400 Bad Request Content-Type: application/json; charset=utf-8 { "error": "url must be an absolute HTTP or HTTPS URL" }

源媒体域名白名单

生产环境建议配置 IMAGE_URL_ALLOWLIST，限制接口只能下载可信域名下的媒体。 

IMAGE_URL_ALLOWLIST=example.com,trusted-cdn.com

配置规则：

  • example.com：允许根域名和所有子域名。
  • *：允许所有域名，仅建议本地开发使用。

响应状态码

状态码 说明
200 成功处理或降级返回原媒体。
400 请求参数缺失或非法，或源域名不在白名单。
405 请求方法不是 GET（单图）或 POST（批量）。
502 源媒体无法下载、超时或处理失败。
