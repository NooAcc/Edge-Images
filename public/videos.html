视频处理

自动识别 MP4 和 WebM 文件，提取首帧作为封面图，支持视频元信息查询。

功能说明

自动识别 .mp4 和 .webm 文件，提取首帧作为封面图。采用 Range 请求优化，仅下载前 512KB 数据。

提取视频封面

/api/media/https%3A%2F%2Fexample.com%2Fclip.mp4?width=800&height=600&fit=cover

HTML 示例

<img
  src="/api/media/https%3A%2F%2Fexample.com%2Fclip.mp4?width=800&height=600&fit=cover"
  alt="视频封面"
>

获取视频元信息

/api/media/https%3A%2F%2Fexample.com%2Fclip.mp4?format=json

JSON 返回示例

{ "width": 1920, "height": 1080, "codec": "h264", "duration": 10.5, "format": "mov,mp4,m4a,3gp,3g2,mj2", "sourceUrl": "https://example.com/clip.mp4", "sourceSize": 8349123 }

视频元信息字段说明

字段 说明
width 视频宽度（像素）
height 视频高度（像素）
codec 视频编码格式（如 h264、vp9）
duration 视频时长（秒）
format 容器格式
sourceSize 源文件总字节数；源站没有提供可靠大小响应头时为 null
