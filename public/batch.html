批量处理

一次请求处理多张图片或视频。支持同步模式（最多 20 张，等待返回）和异步模式（最多 50 张，回调通知）。

功能说明

一次请求处理多张图片或视频，支持所有单图处理功能，包括视频封面提取和元信息查询。

同步模式（/api/batch）：最多 20 张，采用两阶段队列处理——第一阶段并发下载所有源媒体（有缓存则跳过），第二阶段并发执行图片处理，全部完成后返回结果。

异步模式（/api/batch/async）：最多 50 张，服务端立即返回 202 Accepted，后台处理完成后通过 callbackUrl POST 回调结果。回调失败时最多重试 3 次（指数退避）。

同步批量 - 快速调用

POST /api/batch 
curl -X POST /api/batch \
  -H "Content-Type: application/json" \
  -d '[
    {"uuid":"img-001","url":"https://example.com/a.jpg","params":{"width":200,"height":200}},
    {"uuid":"img-002","url":"https://example.com/b.png","params":{"format":"json"}}
  ]'

请求头

请求头 说明 示例
Content-Type 必填。指定请求体格式。 application/json

请求体

JSON 数组，每个元素包含：

字段 类型 必填 说明
uuid string 是 唯一标识符，用于关联响应结果
url string 是 图片地址（http/https）
params object 否 处理参数，支持 width、height、quality、crop、size、format、rotate、flip、background

请求示例

POST /api/batch HTTP/1.1 Host: your-domain.com Content-Type: application/json [ { "uuid": "img-001", "url": "https://example.com/photo.jpg", "params": { "width": 200, "height": 200, "format": "webp" } }, { "uuid": "img-002", "url": "https://example.com/logo.png", "params": { "width": 100 } }, { "uuid": "meta-001", "url": "https://example.com/banner.jpg", "params": { "format": "json" } } ]

响应体

JSON 对象，以 uuid 为键。每个结果包含：

字段 类型 说明
success boolean 是否处理成功
data object 成功时返回。普通图片包含 base64 和 contentType 字段；format=json 包含元数据
error string 失败时返回错误信息

成功响应示例

HTTP/1.1 200 OK Content-Type: application/json; charset=utf-8 { "img-001": { "success": true, "data": { "base64": "UklGRi...", "contentType": "image/webp" } }, "img-002": { "success": true, "data": { "base64": "iVBORw0K...", "contentType": "image/png" } }, "meta-001": { "success": true, "data": { "width": 1920, "height": 1080, "format": "jpeg", "channels": 3, "sourceUrl": "https://example.com/banner.jpg", "sourceContentType": "image/jpeg", "sourceSize": 2483921 } } }

部分失败响应示例

HTTP/1.1 200 OK Content-Type: application/json; charset=utf-8 { "img-001": { "success": true, "data": { "base64": "UklGRi...", "contentType": "image/webp" } }, "img-002": { "success": false, "error": "Source fetch failed" } }

错误响应

状态码 说明
400 请求体不是数组、缺少 uuid/url、uuid 重复、或超过 20 张限制
405 请求方法不是 POST

异步批量 - 快速调用

POST /api/batch/async 
curl -X POST /api/batch/async \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      {"uuid":"img-001","url":"https://example.com/a.jpg","params":{"width":200}},
      {"uuid":"img-002","url":"https://example.com/b.png","params":{"format":"json"}}
    ],
    "callbackUrl": "https://your-service.com/callback",
    "jobId": "my-job-123"
  }'

异步请求体

字段 类型 必填 说明
items array 是 图片列表，格式同同步批量（最多 50 张）
callbackUrl string 是 处理完成后接收结果的回调地址
jobId string 否 自定义任务 ID，不填则自动生成

异步即时响应（202 Accepted）

{ "jobId": "my-job-123", "status": "accepted" }

回调响应体

处理完成后，服务端 POST 以下 JSON 到 callbackUrl：

字段 类型 说明
jobId string 任务 ID
status string completed（全部成功）或 partial（部分失败）
items array 原始请求项列表（uuid、url、params）
results object 以 uuid 为键的结果映射，格式同同步批量响应
timestamp string ISO 8601 时间戳

回调响应示例

POST https://your-service.com/callback Content-Type: application/json; charset=utf-8 X-Job-ID: my-job-123 { "jobId": "my-job-123", "status": "completed", "items": [ {"uuid": "img-001", "url": "https://example.com/a.jpg", "params": {"width": 200}}, {"uuid": "img-002", "url": "https://example.com/b.png", "params": {"format": "json"}} ], "results": { "img-001": { "success": true, "data": {"base64": "UklGRi...", "contentType": "image/webp"} }, "img-002": { "success": true, "data": {"width": 800, "height": 600, "format": "png", "channels": 4, "sourceUrl": "https://example.com/b.png", "sourceContentType": "image/png", "sourceSize": 123456} } }, "timestamp": "2026-06-01T12:00:00Z" }
