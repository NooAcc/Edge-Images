I Edge Image
功能 图片处理 视频处理 批量处理 API

Node.js 媒体处理服务

动态媒体处理服务

传入远程图片或视频 URL，自动完成缩放、裁剪、格式转换。支持 Vercel 和 Docker 部署，根据平台自动优化参数和缓存策略。

开始使用 查看文档
WebP / JPEG / PNG / AVIF

核心功能

图片处理

支持缩放、裁剪、旋转、翻转，输出 WebP/JPEG/PNG/AVIF

批量处理

两阶段队列：先并发下载源媒体，再限流处理，支持全局并发控制

视频封面

自动提取 MP4/WebM 视频首帧作为封面图

平台感知

根据部署平台自动调整参数上限和缓存策略

两级缓存

Docker 部署自动启用内存 LRU + 磁盘缓存，减少重复处理

元信息查询

获取图片或视频的分辨率、大小等详细信息

安全控制

支持源媒体域名白名单，防止滥用

快速调用

单图处理

/api/media/https%3A%2F%2Fexample.com%2Fmedia.jpg?width=800&height=600&fit=cover

源地址需要 URL 编码，直接放入 <img> 的 src 属性即可使用。

批量处理 （仅 Hugging Face 平台）

POST /api/batch 
curl -X POST /api/batch \
  -H "Content-Type: application/json" \
  -d '[
    {"uuid":"img-001","url":"https://example.com/a.jpg","params":{"width":200}},
    {"uuid":"img-002","url":"https://example.com/b.png","params":{"format":"json"}}
  ]'
